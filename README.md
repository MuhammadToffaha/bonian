# 🏢 بُنيان — Bonian

إدارة حسابات العمارة من الموبايل: الشهرية، المصروفات، المتأخرات، التقارير، والسكان.

## ✨ المميزات
- 📊 لوحة رئيسية شهري/سنوي: الإيرادات، المصروفات، رصيد الصندوق، المتأخرات
- 💰 تسجيل تحصيل + إيصال واتساب للساكن
- 🧾 تسجيل مصروف بالبنود (كهرباء، مياه، مصعد، نظافة، بواب، صيانة…)
- 🏢 ضبط شهرية العمارة مع سجل تغييرات (الشهور القديمة على السعر القديم)
- 🚪 الشقق: إضافة سريعة، شهرية خاصة، إعفاء، كشف حساب
- 👥 السكان وطلبات الانضمام (لصق رسالة الطلب من واتساب)
- 📣 إشعارات بقوالب جاهزة + تذكير المتأخرين واتساب
- 🎤 إدخال ذكي بالصوت أو الكتابة: «حصلت 300 من شقة 5» / «صرفت ميتين كهرباء»
- 📞 أرقام الطوارئ والخدمات
- 🔐 كلمة سر للإدارة: الكل يشوف، والتعديل بكلمة السر بس (قفل تلقائي بعد 5 دقايق)
- 🏘️ أكثر من عمارة، 🌙 وضع ليلي، 💾 نسخ احتياطي واسترجاع، 📑 تصدير Excel (CSV)
- 🤫 تحديث تلقائي صامت مرة يومياً + 🎁 نافذة تحديث عند الفتح

## 📲 التثبيت
نزّل `bonian.apk` من [آخر إصدار](https://github.com/MuhammadToffaha/bonian/releases/latest) أو من تطبيق **JAMA**.

كل البيانات على الموبايل (بدون سيرفر).
